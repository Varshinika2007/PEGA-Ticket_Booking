# 🎟️ Ticket Booking System

A modern web-based **Ticket Booking System** that provides users with a simple and seamless way to discover events, select seats, book tickets, and receive digital tickets.

## ✨ Features

* 👤 User Registration & Login
* 🎫 Browse and Search Events
* 📋 Event Details
* 💺 Interactive Seat Selection
* 🧾 Booking Summary
* 💳 Mock Payment
* 🎟️ Digital Ticket with QR Code
* 📱 Responsive & User-Friendly UI

## 🛠️ Technologies

**Frontend:** HTML5, CSS3, JavaScript
**Backend:** Java, Spring Boot *(planned)*
**Database:** MySQL *(planned)*

## 🔄 User Flow

```text
Login → Dashboard → Events → Event Details
→ Select Seats → Booking → Payment → Digital Ticket
```
